{\footnotesize\ttfamily \label{group__MPU_gad8290908b2c33ce92fae22535c5c88b0} 
uint8\+\_\+t init\+\_\+mpu (\begin{DoxyParamCaption}\item[{\doxymbox{\hyperlink{structmpu__region__t}{mpu\+\_\+region\+\_\+t}}}]{regions}{\+[\+MPU\+\_\+\+REGIONS\+\_\+\+NUM]\+}\end{DoxyParamCaption})\hspace{0.3cm}{\ttfamily [inline]}, {\ttfamily [static]}}



Configure and enable the Memory Protection Unit (MPU). 

This function installs the MPU regions used to isolate privileged kernel memory, unprivileged user memory, flash regions, peripheral access, and the kernel stack guard region.

\begin{DoxyReturn}{Returns}
0 on success, or {\ttfamily \doxylink{group__MPU_gaa27628297268fb669450d0e004d5c7d0}{ENOPOINTER}} if {\ttfamily regions} is NULL.
\end{DoxyReturn}
\begin{DoxyPostcond}{Postcondition}
The MPU is enabled with the memory layout required by the HSM privilege-\/separation model. 
\end{DoxyPostcond}
\begin{DoxyNote}{Note}
The configured regions restrict unprivileged access to privileged kernel memory and protect the kernel stack with a dedicated no-\/access guard region. 
\end{DoxyNote}
\begin{DoxyWarning}{Warning}
This function assumes Cortex-\/\+M0+ MPU with DREGION=8; re-\/validate MPU\+\_\+\+TYPE.\+DREGION when writing MPU protections for a different ARM MCU. 
\end{DoxyWarning}
