Configure and enable the Memory Protection Unit (MPU). 

This function installs the MPU regions used to isolate privileged kernel memory, unprivileged user memory, flash regions, peripheral access, and the kernel stack guard region.


\begin{DoxyParams}{Parameters}
{\em regions} & An array of {\ttfamily \doxylink{structmpu__region__t}{mpu\+\_\+region\+\_\+t}} structures defining the MPU regions to configure.\\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
0 on success, or {\ttfamily \doxylink{group__MSPM0L2228__MPU_gaa27628297268fb669450d0e004d5c7d0}{ENOPOINTER}} if {\ttfamily regions} is NULL.
\end{DoxyReturn}
\begin{DoxyPostcond}{Postcondition}
The MPU is enabled with the memory layout required by the HSM privilege-\/separation model. 
\end{DoxyPostcond}
\begin{DoxyNote}{Note}
depending on the firmware\textquotesingle{}s memory layout, the configured regions can restrict unprivileged access to privileged kernel memory and protect the kernel stack with a dedicated no-\/access guard region. 
\end{DoxyNote}
\begin{DoxyWarning}{Warning}
This function assumes Cortex-\/\+M0+ MPU with DREGION=8; re-\/validate MPU\+\_\+\+TYPE.\+DREGION when writing MPU protections for a different ARM MCU. 
\end{DoxyWarning}
