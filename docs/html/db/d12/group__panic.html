int _ca_fullpanic ( void )

Handle any critical error. This function must be called through the ca_panic() macro, which sets a panic flag and then calls this function.

Note
This function should never return and is designed to halt the system in a safe state. It can be used to catch any critical errors or unexpected conditions that occur during execution, such as invalid memory access, failed integrity checks, or other unrecoverable errors.
Warning
This function will enter an infinite loop, effectively halting the system. It should only be used in situations where recovery is not possible or safe, and it should be called through the ca_panic() macro to ensure the panic flag is set correctly.
